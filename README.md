# Neon Nexus GameZone

Futuristic PlayStation-style gaming website with:

- Neon / 3D visual design
- Responsive mobile layout
- Animated hero section
- Gaming station cards
- Game categories
- Pricing section
- Tournament section
- Booking form
- Particle effects and interactive tilt animations

## Run locally

Open `index.html` in a browser.

## Files

- `index.html`
- `style.css`
- `script.js`

Photos are loaded from Unsplash and require internet access.
